# Top GitHub repos: 2026-11-12

## TL;DR
- **Coding agents are the dominant theme.** Seven of the 15 picks exist to feed, secure, host or cheaply run AI coding agents (modern-web-guidance, agent-skills, codex-security, free-claude-code, qwen-code, OpenBot, agentes-chat).
- **"Agent-ready" is now a design goal for ordinary tools.** Meta's Astryx design system, Google Chrome's web guidance and the ZigZag embroidery app all ship CLIs, docs or MCP servers aimed at agents as much as at people.
- **Agents are reaching into the physical and personal world.** `pinky` lets agents drive your phone, ZigZag exposes an embroidery editor over MCP, and `supermimic` targets humanoid-robot control.
- **iOS tinkering is viral.** GestaltX (an iOS system-config editor) went from 0 to about 7k stars in 3 days.
- **Spam warning.** The "created in last 7 days" search is polluted by ~10 fake "cracked software installer" repos with ~1,200 stars and 0-1 forks each, created within minutes of each other. They were excluded as star-farmed or likely malware lures.

Notes: This is the first report in `ideas/` (no earlier reports existed), so no repeats are flagged. "Stars today" comes from GitHub Trending (daily) and is "unknown" where the repo wasn't listed there. Star totals are from the GitHub API at write time. Repo pages (not just APIs) were read in full only for some picks. For others, design notes rely on the API description and are marked as limited.

## 1. meta/astryx
- **What it is:** [meta/astryx](https://github.com/meta/astryx), by Meta. TypeScript, MIT. Beta.
- **Domain:** Frontend / design systems.
- **What it solves:** Gives teams a ready, accessible UI kit that people *and* AI assistants can use the same way. It grew inside Meta over about eight years.
- **General design:** 150+ typed React components in three layers: Foundations (type, color, layout, accessibility), Components, and Patterns (e.g. table pages, form wizards). Monorepo packages: `@astryxdesign/core`, `cli` (docs, templates, scaffolding, codemods), `build` (StyleX plugins) and seven themes. Styles are written in StyleX, but you can override with `className` (Tailwind, CSS modules, plain CSS). Themes are CSS custom-property overrides. A `swizzle` command copies a component's source into your project so you own it. Requires React 19+. Unlike most kits (MUI, Chakra), the CLI and docs are explicitly built for agents too.
- **Traction:** +1,830 stars today, 26,819 total, 2,082 forks, 620 open issues. Created 2026-01-09. Last push 2026-11-13. No GitHub release listed. HN discussion: not found.

## 4. GoogleChrome/modern-web-guidance-src
- **What it is:** [GoogleChrome/modern-web-guidance-src](https://github.com/GoogleChrome/modern-web-guidance-src). TypeScript, Apache-2.0. Stewarded by the Chrome, Edge, Firefox and MDN teams.
- **Domain:** AI agents / web platform.
- **What it solves:** Coding models often write outdated web code (legacy patterns, heavy libraries). This gives agents current best practices and browser-compatibility data.
- **General design:** A set of short "skills"/guides covering 250 web features and 203 real-world use cases. Install with `npx modern-web-guidance@latest install`. The CLI has `search`, `retrieve` (by ID) and `legacy-scan` (finds legacy patterns in your codebase). Guides are kept short for token efficiency, and evals prune content models already know. Prefers native platform APIs over polyfills.
- **Traction:** +739 stars today, 3,487 total, 217 forks, 385 open issues. Created 2026-01-27; 1,592 commits. No release shown. HN: not found.

## 5. openai/codex-security
- **What it is:** [openai/codex-security](https://github.com/openai/codex-security). TypeScript, Apache-2.0.
- **Domain:** Security / AI.
- **What it solves:** Finds, validates and fixes vulnerabilities in code, for security and engineering teams who want fewer false positives.
- **General design:** CLI (`cs` / `codex-security`), TypeScript SDK, GitHub Action and a Codex workflow. Standard scans investigate code; Deep scans repeat and merge deduplicated findings. It can validate candidate findings, write patches, verify fixes, draft `SECURITY.md` and threat models, import other scanners' results, sync to Linear/Jira/GitHub and export SARIF/JSON/CSV. Local-first; Cloud is optional. Works with OpenAI, Bedrock, OpenRouter and Fireworks. Needs Node 22.13+/24/26 and Python 3.10+.
- **Traction:** +643 stars today, 12,609 total, 985 forks, 146 open issues. Created 2026-07-13. Last push 2026-11-13. No release shown. HN: not found.

## 13. simpsoka/zigzag
- **What it is:** [simpsoka/zigzag](https://github.com/simpsoka/zigzag). Rust, Apache-2.0.
- **Domain:** Creative tools / hardware freedom.
- **What it solves:** Author's $300 embroidery machine needed a subscription, so they built free software for Mac and Windows: SVG to machine embroidery, visual stitch editing, and an MCP server so agents (Claude Code etc.) can edit the open design.
- **General design:** Modular Rust: SVG import (usvg), document model, stitch generators (tatami fill, satin, running, contour, appliqué), a planner (hides overlapped fill, orders colors, routes travel stitches, trims), design checks, writers for PES/DST/EXP/JEF/VP3, and a Bluetooth uploader for the Brother Skitch PP1. GPU-rendered editor. Every MCP call is one undo step; `batch` is all-or-nothing. Missing: gradient fills, built-in fonts, multi-hooping.
- **Traction:** Stars today unknown, 323 total, 19 forks, 1 open issue. Created 2026-10-30. Last push 2026-11-13. **HN:** [Show HN, 425 points, 166 comments](https://news.ycombinator.com/item?id=50470488). Picked for HN significance rather than star count.
