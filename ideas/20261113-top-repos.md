# Top GitHub repos: 2026-11-13

## TL;DR
- **Agent tooling still dominates.** Six picks exist to guide, review, secure or oversee AI coding agents: Chrome's modern-web-guidance, OpenAI's codex-security, Alibaba's open-code-review, plannotator, agentes-chat and the stock-analysis agent.
- **Big-company agent releases are the fastest risers.** GoogleChrome/modern-web-guidance-src gained about 1,900 stars in a day. openai/codex-security gained about 750.
- **Local-first and privacy-first apps are popular.** Yogurt (local meeting notes), DeepSeek's no-backend chat demo, and Tailscale's `tailcat` all avoid central servers or accounts.
- **Infrastructure milestone.** `ggml` (the tensor library under llama.cpp) tagged v1.0.0 on 2026-11-13 and reached about 122 points on HN.
- **Caution flags.** Several fast risers are iOS jailbreak-style tools or a Switch-on-iPhone emulator (GestaltX, S2Arm). They are included for their traction, but they are borderline: use at your own risk, and S2Arm carries legal exposure.

**Method notes.** "Stars today" comes from the GitHub Trending daily page where the repo was listed, and is "unknown" otherwise. Total stars, forks and dates come from the GitHub API, or from the search API for newly created repos, fetched on 2026-11-13/14. Contributor counts and most release info were not retrieved ("unknown"). Only the Trending page, search API results, HN front page and READMEs were used. Language-specific trending pages and Reddit were not checked. Repos with a repeat appearance are marked "also featured 2026-11-12". I checked only the 2026-11-12 report's content. A star-farmed "cracked software" cluster seen yesterday was ignored again.

## 1. GoogleChrome/modern-web-guidance-src
- **What it is:** [GoogleChrome/modern-web-guidance-src](https://github.com/GoogleChrome/modern-web-guidance-src). TypeScript, Apache-2.0. *Also featured 2026-11-12 (rank 4, 3,487 stars). Total stars rose by about 1,560 since.*
- **Domain:** AI agents / web platform.
- **What it solves:** Coding agents tend to write outdated web code (old JS libraries instead of native browser features). This gives them up-to-date guidance. For web developers using AI assistants.
- **General design:** A set of "skills" covering about 250 web features and 200 use cases (CSS, HTML/DOM, forms, performance, accessibility, security, PWAs, built-in AI). Content is trimmed to what models don't already know, to save tokens. A CLI (`npx modern-web-guidance@latest install`) installs it. `search`, `retrieve` and `legacy-scan` commands find guides, fetch one, or scan a codebase for outdated patterns. Stewarded by Chrome, Edge, Firefox and MDN teams, which sets it apart from vendor-neutral prompt packs.
- **Traction:** +1,925 stars today, 5,045 total, 276 forks, 389 open issues. Created 2026-01-27. Latest release: unknown. HN discussion: not found.

## 2. we-promise/sure
- **What it is:** [we-promise/sure](https://github.com/we-promise/sure). Ruby, AGPL-3.0. *Also featured 2026-11-12 (rank 2, 14,119 stars).*

- **What it solves:** A self-hostable money-tracking and wealth app for individuals who don't want a closed SaaS.

## 3. openai/codex-security
- **What it is:** [openai/codex-security](https://github.com/openai/codex-security). TypeScript, Apache-2.0. *Also featured 2026-11-12 (rank 5, 12,609 stars).*
- **Domain:** Security / AI.
- **What it solves:** Finding real vulnerabilities, not just warnings, and proposing fixes. For maintainers and security teams.
- **General design:** CLI (`cs scan .`), TypeScript SDK, GitHub Action and containerized bulk-scan setups. Scans a whole repo, paths or a git diff, in standard or deep mode. Candidate findings are validated before reporting, patches can be generated, and earlier fixes re-checked. Reads `SECURITY.md`, can draft threat models, and exports SARIF/JSON/CSV. Works with OpenAI, Bedrock, OpenRouter and others.
- **Traction:** +751 stars today, 13,243 total, 1,027 forks, 170 open issues. Created 2026-07-13. Latest release: unknown.

## 4. huamidev/GestaltX (borderline)
- **What it is:** [huamidev/GestaltX](https://github.com/huamidev/GestaltX). Swift, GPL-3.0. *Also featured 2026-11-12 (rank 8, 7,029 stars).*
- **Domain:** iOS tooling.
- **What it solves:** Lets users edit Apple's MobileGestalt device-config data (region codes, device presets, Apple Intelligence flags) on iOS/iPadOS 27.x.
- **General design:** Native app that reads MobileGestalt via the `worse_query` library, stages edits for review, and backs up originals before each write. Plist import via a share extension. Borderline pick: very fast growth, but a system-tampering tool.

## 5. alibaba/open-code-review
- **What it is:** [alibaba/open-code-review](https://github.com/alibaba/open-code-review). Go, Apache-2.0.
- **Domain:** AI code review.
- **What it solves:** Automated, line-level review comments on diffs that are cheaper and more repeatable than a pure LLM review.
- **General design:** Fixed logic chooses files, bundles related ones, matches rules and validates comment locations. An LLM agent with tools handles context retrieval and judgment. `ocr review` for diffs, `ocr scan` for whole files. A delegation mode lets another agent (e.g. Claude Code) do the review. Needs Git 2.41+. Originated as Alibaba's internal review assistant.
- **Traction:** +215 stars today, 50,802 total, 3,782 forks, 340 open issues. Created 2026-05-18. Latest release: unknown.

## 6. ggml-org/ggml
- **What it is:** [ggml-org/ggml](https://github.com/ggml-org/ggml). C++, MIT.
- **Domain:** ML infrastructure.
- **What it solves:** A small tensor library for running models on many kinds of hardware. It's the engine under llama.cpp and whisper.cpp.
- **General design:** v1.0.0 (2026-11-13) removes deprecated public API and old ops, and bumps the RPC protocol so incompatible peers are rejected. It adds FP8 support, configurable YaRN truncation, and backend work: CUDA, Metal (fused MoE routing), Vulkan (Intel FlashAttention), SYCL, OpenCL (Adreno), WebGPU and Hexagon.
- **Traction:** Stars today unknown. 15,663 total, 1,940 forks, 386 open issues. Created 2022-09-18. Release v1.0.0 on 2026-11-13. HN: ["Ggml v1.0.0"](https://news.ycombinator.com/item?id=50493062), 122 points, 21 comments.

## 7. tailscale/tailcat
- **What it is:** [tailscale/tailcat](https://github.com/tailscale/tailcat). Go, BSD-3-Clause.
- **Domain:** Networking.
- **What it solves:** Quick, encrypted, NAT-traversing connections between two machines without a Tailscale account, root, or routing changes.
- **General design:** A server prints a short `tc...` address that embeds public keys, an optional pre-shared key and DERP relay info. Peers connect through a DERP relay, then upgrade to direct UDP where possible. Traffic is WireGuard-encrypted. A userspace gVisor netstack avoids needing a TUN device. Pipes stdin/stdout, forwards ports, transfers files, runs SSH. No API or CLI stability guarantees.
- **Traction:** +256 stars today, 9,557 total, 435 forks, 42 open issues. Created 2024-10-29. Last push 2026-11-05. Latest release: unknown.

## 8. jhaizhou-ops/S2Arm (borderline)

- **Domain:** Emulation / porting.
- **What it solves:** Runs users' own 64-bit Nintendo Switch games on iPhone, iPad and Mac.

## 13. Th0rgal/satmux
- **What it is:** [Th0rgal/satmux](https://github.com/Th0rgal/satmux). Python (zero dependencies), MIT.
- **Domain:** Networking.
- **What it solves:** In-flight GEO satellite Wi-Fi is slow (about 620 ms round trips, DNS interception, port-443 resets, loss).
- **General design:** A laptop holds 12 warm connections to a Linux VM on the ground. The VM does DNS, TLS and HTTP over fiber and zlib-compresses responses over the satellite link. Local SOCKS5/HTTP CONNECT proxies open streams almost instantly. BBR congestion control, 1280-byte MSS. README reports 2x to 5x speedups, which I haven't verified.
- **Traction:** Stars today unknown. 1,078 total, 51 forks. Created 2026-11-07. Latest release: unknown.
