# Top GitHub repos: 2026-11-14

## TL;DR
- **AI coding-agent tooling still dominates.** Nine of 15 picks exist to guide, review, oversee or cheapen coding agents: modern-web-guidance-src, open-code-review, chrome-devtools-mcp, plannotator, claude-trading-skills, caveman, Univer (agent-ready office SDK), and more.
- **Big-company agent releases lead the day's star gains.** Google Chrome's modern-web-guidance-src (+1,231) and Alibaba's open-code-review (+893) topped the daily Trending page among the repos I picked.
- **Review and oversight of agents is the hot sub-theme.** Alibaba's reviewer, plannotator and caveman all try to keep agents cheaper or more controllable.
- **Local inference and local AI apps keep climbing.** TensorFold (Zig inference engine), Yogurt (local meeting notes) and DeepSeek's backend-less chat demo.
- **Caution flags.** GestaltX (iOS system tweaking) is borderline: it is a device-modification tool with real risk. Caveman's headline claims are self-reported and inconsistent. ANR has no source yet.

**Method notes.** "Stars today" comes from the GitHub Trending daily page (fetched 2026-11-14) and is "unknown" for repos not listed there. Total stars, forks, dates and licenses come from the GitHub API or search API. Contributor counts and release details were mostly not retrievable ("unknown"). Language-specific trending pages and Reddit were not checked. Hacker News front page was checked; none of these repos appeared on it, so HN discussion is "not found". I looked only at the 2026-11-13 report for repeats.

## 1. GoogleChrome/modern-web-guidance-src
- **What it is:** [GoogleChrome/modern-web-guidance-src](https://github.com/GoogleChrome/modern-web-guidance-src). TypeScript, Apache-2.0. *Also featured 2026-11-13 (rank 1, 5,045 stars); total stars rose by about 1,210 since.*
- **Domain:** AI agents / web platform.
- **What it solves:** Coding agents often write outdated web code. This feeds them current best-practice guidance. For web developers using AI assistants.
- **General design:** Skills covering about 250 web features (per yesterday's report), installed with an `npx` CLI, with search, retrieve and legacy-scan commands. Stewarded by browser vendors, unlike vendor-neutral prompt packs.
- **Traction:** +1,231 stars today, 6,255 total, 456 forks, 391 open issues. Created 2026-01-27. Last push 2026-11-14. Latest release: unknown. HN: not found.

## 2. alibaba/open-code-review
- **What it is:** [alibaba/open-code-review](https://github.com/alibaba/open-code-review). Go, Apache-2.0. *Also featured 2026-11-13 (rank 5, 50,802 stars); about 740 more stars since.*
- **Domain:** AI code review.
- **What it solves:** LLM reviews are expensive and noisy. This tries to give precise line-level comments at low token cost. For teams reviewing diffs and auditing unfamiliar code.
- **General design:** A CLI (`ocr`, installed with `npm install -g @alibaba-group/open-code-review`; needs Git 2.41+). It reads Git diffs, bundles related files into sub-agent units with isolated context, matches rule templates (NPE, thread safety, XSS, SQL injection) deterministically, and uses an LLM agent with file-reading and search tools. Separate modules check comment location and content. It works with OpenAI- or Anthropic-compatible APIs, or "delegation mode" lets your coding agent do the reviewing. The README reports higher precision and F1 than Claude Code on the same model with about 1/9 of the tokens on AACR-Bench (50 repos, 200 PRs), but lower recall. Those figures are the authors' own.
- **Traction:** +893 stars today, 51,539 total, 3,959 forks, 341 open issues. Created 2026-05-18. Latest release: unknown. HN: not found.

## 8. backnotprop/plannotator
- **What it is:** [backnotprop/plannotator](https://github.com/backnotprop/plannotator). TypeScript, Apache-2.0. *Also featured 2026-11-13 (rank 11, 10,546 stars); about 760 more since.*
- **Domain:** AI agents / developer tools.
- **What it solves:** Lets you review an agent's plan or diff visually, annotate it, and send structured feedback back.
- **General design:** A local server and browser UI launched by agent hooks (for Claude Code, a plan-approval hook). Plan revisions are diffed. Local-first; network features are opt-in, though it checks GitHub for updates with no opt-out. In remote (SSH) mode it listens on all interfaces without a login, so be careful.
- **Traction:** +408 stars today, 11,303 total, 963 forks, 228 open issues. Created 2025-12-28. Latest release: unknown (v0.17.2 is mentioned in the README). HN: not found.

## 9. JuliusBrussee/caveman
- **What it is:** [JuliusBrussee/caveman](https://github.com/JuliusBrussee/caveman). Go, Apache-2.0.
- **Domain:** AI agents / cost.
- **What it solves:** Cuts token spend of coding agents. Terse responses, compressed logs and tool output, model routing. Borderline: its claims are self-reported.
