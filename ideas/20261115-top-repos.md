# Top GitHub repos: 2026-11-15

## TL;DR
- **AI coding-agent tooling still owns the chart.** Twelve of 15 picks exist to guide, review, supervise, orchestrate or connect coding agents (modern-web-guidance-src, plannotator, chrome-devtools-mcp, open-code-review, ag-ui, LoopForge, skills bundles, SkillEvaluator and more).
- **Big-company releases lead the star gains.** Google Chrome's modern-web-guidance-src (+1,219) and the Univer office SDK (+988) topped the daily Trending page.
- **"Skills" are becoming a packaging format.** Stitch skills (Google), claude-trading-skills and NVIDIA's SkillEvaluator show skills being published, and now tested, like libraries.
- **Fast-rising new repos.** DeepSeek's chat-demo grew from 1,874 to 3,420 stars in a day and Yogurt (local meeting notes) keeps climbing. Both are new this week.
- **Caution flags.** GestaltX modifies iOS system files (borderline, risky). mkw-recomp is a game recompilation project with legal grey areas. The Blender MCP add-on is only days old with no language detected.

**Method notes.** "Stars today" is from the GitHub Trending daily page (fetched 2026-11-15). It is "unknown" for repos not on that page. Totals, forks, dates, licenses and open issues come from the GitHub API (`api.github.com/repos/...`) fetched the same day. Latest release, contributor counts and most HN discussion were not retrievable, so they are "unknown" or "not found". Language-specific trending pages and Reddit were not checked. Design notes are drawn from repo descriptions and earlier reports. I did not re-read every README, so they are high-level. Repeat markers compare against the 2026-11-14 report.

## 1. GoogleChrome/modern-web-guidance-src
- **What it is:** [GoogleChrome/modern-web-guidance-src](https://github.com/GoogleChrome/modern-web-guidance-src). TypeScript, Apache-2.0. *Also featured 2026-11-14 (rank 1, 6,255 stars); about 1,150 more stars since.*
- **Domain:** AI agents / web platform.
- **What it solves:** Coding agents often write outdated web code. This feeds them current best-practice guidance. For web developers using AI assistants.
- **General design:** Per earlier reports: skills covering about 250 web features, installed with an `npx` CLI with search, retrieve and legacy-scan commands. It is maintained by the Chrome team, which sets it apart from community prompt packs.
- **Traction:** +1,219 stars today, 7,409 total, 633 forks, 403 open issues. Created 2026-01-27. Last push 2026-11-15. Latest release: unknown. HN: not found.

## 6. alibaba/open-code-review
- **What it is:** [alibaba/open-code-review](https://github.com/alibaba/open-code-review). Go, Apache-2.0. *Also featured 2026-11-14 (rank 2, 51,539 stars); about 800 more since.*
- **Domain:** AI code review.
- **What it solves:** LLM reviews are noisy and costly. This aims for precise line-level comments at lower token cost.
- **General design:** A CLI (`ocr`) that reads Git diffs, groups related files into sub-agent units, applies a built-in multi-language ruleset deterministically (NPE, thread safety, XSS, SQL injection), then uses an LLM agent with file-reading and search tools. Works with OpenAI- or Anthropic-compatible APIs. The README's benchmark claims (from yesterday's report) are the authors' own.
- **Traction:** +691 stars today, 52,338 total, 4,166 forks, 349 open issues. Created 2026-05-18. Last push 2026-11-16. Latest release: unknown. HN: not found.

## 7. ag-ui-protocol/ag-ui
- **What it is:** [ag-ui-protocol/ag-ui](https://github.com/ag-ui-protocol/ag-ui). TypeScript, MIT.
- **Domain:** AI agents / frontend.
- **What it solves:** Agents and UIs need a common way to talk (streaming messages, tool calls, state). AG-UI ("Agent-User Interaction Protocol") standardises that so agents can be embedded in front-end apps. Its README is associated with CopilotKit; I did not verify that today.
- **General design:** An open protocol with SDKs rather than a single app: agent backends emit events and the frontend renders them. Details not re-read.
- **Traction:** +355 stars today, 18,102 total, 1,855 forks, 594 open issues. Created 2025-05-07. Last push 2026-11-15. Latest release: unknown. HN: not found.
