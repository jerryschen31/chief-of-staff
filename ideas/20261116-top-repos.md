# Top GitHub repos: 2026-11-16

## TL;DR
- **A big non-AI-agent story broke through: `aws/aws-emulator`.** A Rust local emulator of the AWS APIs, published by AWS itself, has 8.9k stars in about two months and a 992-point Hacker News thread.
- **Agent tooling is still the biggest theme.** Eight of the 15 picks exist to guide, review, evaluate or connect coding agents (BugHunter, open-code-review, SkillEvaluator, chrome-devtools-mcp, AG-UI, Plannotator, Stitch skills, Univer's agent-ready SDK).
- **Local and small-device AI keeps rising.** ggml hit v1.0.0, smolmaxxing runs LLMs on tiny devices, and Yogurt does private on-device meeting notes.
- **Fast-growing new repos.** DeepSeek's chat-demo went from 3,420 to 4,231 stars in a day. Zigzag (open-source embroidery software with an MCP server) reached 741 HN points.
- **Caution flags.** Claude-BugHunter is an offensive-security skill bundle (dual-use). `deepseek-ai/chat-demo` has a very thin description. Stars on `aws-emulator` are not the same as maturity (465 open issues, no pull requests accepted).

**Method notes.** "Stars today" comes from the GitHub Trending daily page fetched 2026-11-16; it is "unknown" for repos not on that page. Totals, forks, dates, licenses and open issues come from `api.github.com/repos/...` fetched the same day. Latest release, contributor counts and most HN thread details were not retrievable, so they are "unknown". I did not check language-specific trending pages or Reddit, and I did not read every README in full; design notes are based on repo descriptions and the pages I could fetch. Repeat markers compare against the 2026-11-15 report. HN points are from the Algolia API.

## 1. aws/aws-emulator
- **What it is:** [aws/aws-emulator](https://github.com/aws/aws-emulator), owned by AWS. Rust, CC0-1.0 (the `vendor/` folder is Apache-2.0).
- **Domain:** Cloud development tools.
- **What it solves:** Lets you test code against AWS APIs locally, without an AWS account or network calls. Aimed at developers and CI pipelines. README says it is for building and testing, not production or security testing.
- **General design:** A Rust workspace. A router binary mounts every service on one HTTPS endpoint (`127.0.0.1:9297`, self-signed certificate); you point the AWS CLI or SDK at it with environment variables. An "embedded" mode compiles the emulator into your test binary for one isolated instance per test. Each service is its own crate, driven by its Smithy model (AWS's API definition format), with in-memory state and one file per operation. Fidelity is tracked per release, with known gaps listed in the repo. Telemetry is on by default and can be turned off. Linux source builds only; Docker on macOS/Windows. The README does not compare it to LocalStack, so I won't claim a comparison. Unusually, it does not accept pull requests.
- **Traction:** Stars today unknown. 8,915 stars, 398 forks, 465 open issues. Created 2026-09-11. Last push 2026-11-17 UTC. Latest release: unknown. HN: [992 points, 266 comments](https://news.ycombinator.com/item?id=50456631).

## 4. alibaba/open-code-review
- **What it is:** [alibaba/open-code-review](https://github.com/alibaba/open-code-review). Go, Apache-2.0. *Also featured 2026-11-15 (rank 6, 52,338 stars); about 780 more since.*
- **Domain:** AI code review.
- **What it solves:** LLM-only reviews are noisy and inconsistent. This mixes fixed rules with an LLM agent, for teams wanting automated pull request review.
- **General design:** A hybrid: a deterministic pipeline with built-in multi-language rules (null pointers, thread safety, XSS, SQL injection) plus an LLM agent, producing line-level comments. Supports OpenAI and Anthropic APIs.
- **Traction:** +951 stars today, 53,121 total, 4,334 forks, 349 open issues. Created 2026-05-18, so roughly 53k stars in six months. Last push 2026-11-17. Latest release: unknown. HN: not found.
