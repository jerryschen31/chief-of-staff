# Top MCP repos: 2026-11-17

## TL;DR
- **Skills are arriving inside MCP.** FastMCP 4.2.0 (2026-11-13) serves agent "skills" from a server, the TypeScript SDK 2.4.0 added "Skills over MCP" (SEP-2640), and GitHub's MCP server v2.2.0 (2026-11-16, "the one with Skills") replaces its server instructions with filtered skills.
- **Security fixes ship weekly in core tooling.** MCP Inspector 2.14/2.15 and 1.0.5 (Nov 4-12) block cloud-metadata addresses in the proxy, harden `server.json` import and URL elicitation, and authenticate the daemon. FastMCP 4.2.1 (Nov 17) patches its OAuth proxy. The Go SDK 1.9.0-pre.1 stops following cross-origin redirects by default.
- **Phone and device control is a hot niche.** Pinky (new, Go, 2,397 stars) exposes iPhone and Android as MCP tools, with approvals enforced in a gateway rather than in the prompt.
- **The spec is quiet.** The newest spec release I found is `2026-07-28` (stable). The Go SDK pre-release says it is still the newest version negotiated.
- Caveats: GitHub search is full of implausible star counts and clusters of near-identical Blender "copilot" repos created within minutes of each other. I excluded those. "Recent star gain" is **unknown** everywhere, because the API gives totals only. I only skimmed Hacker News, and I did not check Reddit. Figures come from GitHub API and page fetches on 2026-11-17/18 UTC.

## 1. PrefectHQ/fastmcp
**What it is:** FastMCP, by Prefect. Python, Apache-2.0. Tooling (server/client framework). [Repo](https://github.com/PrefectHQ/fastmcp).

**Why it's here:** Two releases in four days. [v4.2.0](https://github.com/PrefectHQ/fastmcp/releases) (2026-11-13) adds server-hosted agent skills: `Skill`, `SkillCatalogProvider`, `Client.read_skill()` with size and digest checks, and `to_directory()` for local installs. Dependencies can be declared in `Annotated` types, and Python 3.11+ is now required. The 4.1 skills API is deprecated and goes in 4.3. v4.2.1 (2026-11-17) is a security patch: it rejects JWTs before their `nbf` time, keeps `required_scopes` with custom verifiers, pins pre-registered OAuth clients to their issuer, and hardens consent and claims handling in the OAuth proxy.

**What it solves:** Writing a Python MCP server without hand-writing protocol code. Skills let one server hand every connected agent the same instructions.

**General design:** Decorator-based tools, resources and prompts, with providers and dependency injection. It speaks stdio and streamable HTTP, and includes an OAuth proxy and token verifiers. I did not read the source.

**Traction:** 28,640 stars, 2,620 forks, 121 watchers. Created 2024-11-30. Latest release v4.2.1 (2026-11-17). Contributors: unknown.

**Takeaway for a macOS MCP server builder:** The skills-over-MCP idea (a server shipping its own usage guide) suits a large Go tool surface. The OAuth proxy fixes are a checklist if you ever expose the server remotely.

## 2. github/github-mcp-server
**What it is:** GitHub's official MCP server. Go, MIT. Server. [Repo](https://github.com/github/github-mcp-server).

**Why it's here:** Borderline repeat (it was in the 2026-11-15 report at v2.1.0). Since then, [v2.2.0](https://github.com/github/github-mcp-server/releases) (2026-11-16) shipped. Highlights: server instructions are replaced with filtered MCP skills, secret-scanning tools gain an option to hide secrets, new agent-automation tools appear, and there were small fixes (empty completion results, validation error capacity).

**What it solves:** Repo, issue, PR and Actions access for agents.

**General design:** Go binary, local stdio or GitHub-hosted remote. Tools are grouped into toolsets. I did not verify further.

**Traction:** 34,554 stars, 5,364 forks, 412 watchers. Created 2025-03-04. Latest release v2.2.0.

**Takeaway for a macOS MCP server builder:** A real-world example of replacing a long instruction blob with on-demand skills, in Go, to save context.

## 3. modelcontextprotocol/inspector
**What it is:** The official MCP Inspector, described as "deterministic testing tools for MCP servers". TypeScript, license listed as "other". Tooling (inspector/testing). [Repo](https://github.com/modelcontextprotocol/inspector).

**Why it's here:** A security-heavy run of releases. [2.15.0](https://github.com/modelcontextprotocol/inspector/releases) (2026-11-12): four security fixes (the fetch guard blocks cloud metadata addresses beyond 169.254.0.0/16; the `server.json` preview shows env var values; POST event-stream recording is capped; `mcpdo` authenticates the daemon before sending credentials), plus load-testing options, per-tool run history in the web UI, OAuth tracing and a smaller hardened Docker image. 1.0.5 (2026-11-11) patches the deprecated v1 proxy to block 100.100.100.200 and 192.0.0.192. 2.14.0 (2026-11-04) kept MCP App sandbox frames within policy and limited URL elicitations to http(s).

**What it solves:** Testing and debugging a server by hand, now with load tests and run history, for anyone building a server.

**General design:** Web UI plus a CLI and a daemon (`mcpdo`). Not read in detail.

**Traction:** 11,321 stars, 1,581 forks, 67 watchers. Created 2024-10-03. Latest 2.15.0.

**Takeaway for a macOS MCP server builder:** Use it for scripted, repeatable checks and load tests of your tools. The deterministic-testing framing fits CI.

## 4. DIYgod/pinky
**What it is:** Pinky, by DIYgod. Go (single binary, no cgo), Apache-2.0. Server (phone control). Pre-alpha per the README. [Repo](https://github.com/DIYgod/pinky).

**Why it's here:** New (created 2026-11-06), pushed 2026-11-18, 2,397 stars in 12 days.

**What it solves:** Letting an agent use a real iPhone or Android phone while a human watches and can intervene.

**General design:** MCP over stdio (`pinkyctl mcp` shim to a local socket) or HTTP with an agent token. A gateway owns sessions, leases, the action pipeline and approvals. Android uses adb and scrcpy plus a Kotlin companion app. iOS uses Apple developer services and WebDriverAgent below iOS 27. SQLite stores task history, FFmpeg handles recording. Tools: `phone_drag`, `phone_launch`, `phone_app`, `phone_logs`, `phone_device`, and task tools (`phone_task_run`, `_wait`, `_status`, `_list`, `_steer`, `_cancel`). Safety: approvals enforced by the gateway; payments wait for a click by default; banking and password apps are hidden; password and one-time-code fields are masked or untypeable; unanswered approvals time out as "no" after 60 seconds; a global Stop-all hotkey (⌥⌘ on macOS); every run is recorded locally. Native GPU UI, no Electron.

**Traction:** 2,397 stars, 254 forks, 19 open issues. Created 2026-11-06. No release verified.

**Takeaway for a macOS MCP server builder:** The closest design to yours. Copy the "approval lives in the gateway, not the prompt" model, the timeout-means-no rule, the global kill hotkey, and the hidden-by-default sensitive apps list. It is also Go and ships via a Homebrew cask.

## 5. modelcontextprotocol/go-sdk
**What it is:** Official Go SDK, maintained with Google. Go, license listed as "other". Tooling (SDK). [Repo](https://github.com/modelcontextprotocol/go-sdk).

**Why it's here:** Repeat from 2026-11-15. Since then, [v1.9.0-pre.1](https://github.com/modelcontextprotocol/go-sdk/releases) (2026-11-17): HTTP clients no longer follow cross-origin or method-changing redirects by default, client caches are capped at 512 entries, `StreamKeepAlive` sends SSE comments on idle POST streams (30s default), per-session notification methods, request-metadata helpers (`OnRequestSummary`, `HasParams`, `Request.GetID`), `ClientSession.Discover`, and eight new `MCPGODEBUG` flags to revert behavior. No new protocol revision.

**What it solves:** The standard way to build Go servers and clients.

**General design:** Typed tool registration, stdio and streamable HTTP transports.

**Traction:** 5,361 stars, 622 forks. Created 2025-04-23. Latest stable v1.8.0 (2026-09-14).

**Takeaway for a macOS MCP server builder:** Directly relevant. The `MCPGODEBUG` flags mean upgrades can be reverted per behavior. Watch the redirect change and the request-summary middleware hooks for logging.

## 6. oomol-lab/open-connector
**What it is:** Open Connector, by oomol-lab. TypeScript, license listed as "other". Tooling (auth gateway). [Repo](https://github.com/oomol-lab/open-connector).

**Why it's here:** [v1.10.0](https://github.com/oomol-lab/open-connector/releases) (2026-11-12): Kubernetes, SFTP and Piloterr providers; Zoom AI Companion summaries; custom MCP servers can be registered as providers; compact MCP tool results are opt-in; OAuth token requests are bound to the authorized resource; encoded traversal segments are rejected in proxy endpoints.

**What it solves:** One authenticated gateway that connects an agent to 1700+ SaaS providers.

**General design:** A gateway holding provider credentials and exposing actions, including through MCP. Details not read.

**Traction:** 6,263 stars, created 2026-06-29. Forks and contributors unknown. Borderline: I could not confirm the star growth is organic.

**Takeaway for a macOS MCP server builder:** Little directly; useful only if you add SaaS-backed tools.

## 8. mksglu/context-mode
**What it is:** context-mode. Server plus hooks, a context manager. License and language: not rechecked. [Repo](https://github.com/mksglu/context-mode).

**Why it's here:** Also featured 2026-11-15; since then, v2.2.0 (2026-11-14) added OMP as the 11th supported agent and v2.2.1 (2026-11-17) fixed Windows file permissions, Android f2fs publishing, recall after compaction and `ctx_search` handling.

**What it solves:** Keeps large tool output out of the model's context and returns searched excerpts.

**Traction:** 34,159 stars as of 2026-11-15 (not rechecked). Borderline: a bug-fix release.

**Takeaway for a macOS MCP server builder:** Large outputs (window trees, screenshots) benefit from handles plus search, a pattern Metabase also describes (see Sources).

## 9. jub0t/Concat
**What it is:** Concat, a free local-first video editor. Rust, AGPL-3.0-or-later (commercial option). Server built into an app: `concat --mcp`. [Repo](https://github.com/jub0t/Concat).

**Why it's here:** New (created 2026-08-25), pushed 2026-11-18, version 0.2.11 beta. I did not find a recent release or a specific MCP update.

**What it solves:** Scripting a video editor from an agent via JSON-RPC and MCP.

**General design:** JSON-RPC API and a built-in MCP mode. Tools and transport are not described on the page I read (setup docs are in `docs/MCP.md`).

**Traction:** 18,478 stars, 2,261 forks, 302 open issues. **Borderline:** the star count is very high for a 12-week-old beta, so it may be inflated. Included for the "app ships its own MCP mode" pattern.

**Takeaway for a macOS MCP server builder:** The "app exposes the same actions to UI, JSON-RPC and MCP" idea is worth a look.
