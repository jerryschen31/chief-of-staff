# Top GitHub repos: 2026-11-17

## TL;DR
- **Agent skills and harnesses dominate again.** Nine of the 15 picks exist to steer, review, orchestrate or extend coding agents (superpowers, ECC, last30days-skill, LoopForge, open-code-review, plannotator, stitch-skills, BugHunter, ag-ui).
- **Agent skills are a mature category.** `obra/superpowers` (319k stars) and `affaan-m/ECC` (306k) are among the biggest repos on the site, and both still gained 880 to 1,900 stars today.
- **Research and office automation by agents.** Google Research's `paper-orchestra` (+1,072) writes research papers with multiple agents, and `univer` pitches an office suite that agents can edit.
- **New-repo breakouts.** `rust-anything` (created 2026-11-16, 1,755 stars) and `deepseek-ai/chat-demo` (4,607 stars in 5 days) lead the fresh repos. `apex-compute/ANR` (neural rendering, 2,609 stars) has no license.
- **Caution flags.** BugHunter is a dual-use security bundle. ANR has no license and almost no description. Several star counts look inflated relative to forks or issues, so treat them as attention, not quality.

**Method notes.** "Stars today" is from the GitHub Trending daily page fetched 2026-11-17; it is "unknown" for repos not on that page. Totals, forks, issues, dates, licenses and languages come from `api.github.com/repos/...` fetched the same day. I could not read each README in full, and I did not retrieve release data, contributor counts or HN threads for these repos, so those are "unknown". Design notes come from API and Trending descriptions, so they are high level. I did not check language-specific trending pages or Reddit. The HN Show HN query I ran returned mostly older posts, so I used no HN data. Repeat markers compare against the 2026-11-15 and 2026-11-16 reports.

## 1. obra/superpowers
- **What it is:** [obra/superpowers](https://github.com/obra/superpowers). Shell, MIT.
- **Domain:** AI coding agents.
- **What it solves:** Gives coding agents a repeatable software-development method (planning, testing, review) delivered as installable "skills", for developers who use agents daily.
- **General design:** A collection of skill files plus shell glue that agents load on demand. Exact structure not verified.
- **Traction:** +1,917 stars today (top of Trending), 319,498 total, 28,486 forks, 358 open issues. Created 2025-10-09. Last push 2026-11-03. Latest release: unknown. Discussion: unknown. Not in the 11-15 or 11-16 reports.
