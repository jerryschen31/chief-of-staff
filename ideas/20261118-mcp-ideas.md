# Top MCP repos: 2026-11-18

## TL;DR
- **Skills over MCP keeps spreading.** FastMCP 4.2.0/4.2.1/4.2.2 (Nov 13/17/18) serve agent skills from the server. The TypeScript SDK 2.4.0 (Oct 23) has SEP-2640 "Skills over MCP". GitHub's server v2.2.0 (Nov 16) swaps its server instructions for filtered skills.
- **A new SSE-size security advisory hit the tooling the same day.** MCP Inspector 2.16.0 and 1.0.6 (Nov 18) cap SSE line and event sizes (GHSA-3xgv-mvj6-g78r) so a hostile upstream can't crash the proxy. Inspector 2.15.0 (Nov 12) closed four other holes.
- **Policy-gated "declared actions" are the safety pattern for infrastructure agents.** emisar ships weekly. The model picks from signed, typed actions, never a raw shell.
- **The spec is quiet.** The newest stable revision is `2026-07-28`. The Go SDK 1.9.0-pre.1 (Nov 17) says it adds no newer one. New servers such as Pitot advertise `2026-07-28` plus older versions.
- **Engine and editor bridges are still a busy niche** (Unreal, Unity). They are good references for large tool surfaces.
- Caveats:
  - Search results include clusters of near-identical Blender "copilot" repos made on 2026-11-12, each at about 500 stars. I excluded them as likely star-farmed.
  - Recent star gain is **unknown** for every repo, because the API gives totals only.
  - I read Hacker News only (the latest MCP stories had 0-4 points). I did not read Reddit.
  - Figures are from GitHub API and page fetches on 2026-11-18/19 UTC.

## 1. modelcontextprotocol/inspector
**What it is:** The official MCP Inspector. TypeScript, license listed as "Other" (NOASSERTION) by the API. Tooling (inspector/testing). [Repo](https://github.com/modelcontextprotocol/inspector).

**Why it's here:** Also featured 2026-11-17 (then at 2.15.0). Since then, [2.16.0 and 1.0.6](https://github.com/modelcontextprotocol/inspector/releases) came out on 2026-11-18.
- Both cap buffered upstream SSE lines and events (16 MiB in 1.0.6) and close the connection on overflow, to stop proxy crashes (GHSA-3xgv-mvj6-g78r).
- 2.16.0 also adds an opt-in per-server cookie jar for sticky sessions and mirrors the SEP-2792 `acceptLanguage` setting to the `Accept-Language` header.
- Known issue: npm audit flags a picomatch ReDoS (GHSA-fc5q-39xc-vjpf), reachable only through vite in `--web --dev`.
- 2.15.0 (Nov 12) had four fixes (metadata-address fetch guard, `server.json` preview confirmation, daemon auth) plus load-testing features.

**What it solves:** Testing, debugging and load-testing an MCP server without a full client. For anyone building servers.

**General design:** Web UI, TUI and CLI (including a `mcpdo` daemon). It acts as a proxy between your server and the UI, so it carries the proxy-hardening work. It also does OAuth tracing (`--oauth-debug`) and handles sampling and elicitation. I did not read the source.

**Traction:** 11,331 stars, 1,581 forks. Created 2024-10-03. Latest 2.16.0 (2026-11-18). Contributors: unknown.

**Takeaway for a macOS MCP server builder:** Use the 2.16 `--load` mode and the per-tool re-run/diff to regression-test your server. Its proxy hardening is a good checklist if you ever add an HTTP transport.

## 2. PrefectHQ/fastmcp
**What it is:** FastMCP, by Prefect. Python, Apache-2.0. Tooling (framework). [Repo](https://github.com/PrefectHQ/fastmcp).

**Why it's here:** Also featured 2026-11-17 (then at v4.2.1). Since then, [v4.2.2](https://github.com/PrefectHQ/fastmcp/releases) (2026-11-18) fixed a skills bug. With a transform like `ResourcesAsTools`, `skills/list` returned nothing even though the files were readable. Earlier: 4.2.0 (Nov 13) added server-hosted skills and 4.2.1 (Nov 17) was an OAuth/JWT security patch, which also raised the `opentelemetry-api` floor past a traceparent ReDoS.

**What it solves:** Building a Python MCP server and sharing one copy of agent instructions across all clients.

**General design:** Decorator-based tools, resources and prompts, with providers, dependency injection, an OAuth proxy and token verifiers. Stdio and streamable HTTP. The 4.1 skills API goes away in 4.3.

**Traction:** 28,662 stars, 2,627 forks, 254 open issues. Created 2024-11-30. Latest v4.2.2.

**Takeaway for a macOS MCP server builder:** The pattern is a server that ships its own usage guide. It would suit a large Go tool surface. The bug is a lesson too: a client that sees only tools can lose skill discovery.

## 4. modelcontextprotocol/go-sdk
**What it is:** The official Go SDK. Go, license "Other" (NOASSERTION). Tooling (SDK). [Repo](https://github.com/modelcontextprotocol/go-sdk).

**Why it's here:** Also featured 2026-11-17, with no newer release since. [v1.9.0-pre.1](https://github.com/modelcontextprotocol/go-sdk/releases) (2026-11-17) is a pre-release.
- HTTP clients no longer follow cross-origin or method-changing redirects.
- Client caches are capped at 512 entries.
- `StreamKeepAlive` sends SSE comments every 30 seconds by default.
- Per-session notifications and request-summary middleware hooks.
- Exact JSON number decoding.
- Eight new `MCPGODEBUG` flags to revert changes, scheduled for removal in v1.11.0.
- `2026-07-28` remains the newest negotiated version.

**What it solves:** Writing Go servers and clients.

**General design:** Typed tool registration, stdio and streamable HTTP transports, `CommandTransport` for spawning servers.

**Traction:** 5,365 stars, 623 forks. Created 2025-04-23.

**Takeaway for a macOS MCP server builder:** This is probably your SDK. Check your server against the `MCPGODEBUG` flags and the JSON-number change before 1.9 stable.

## 5. AndrewDryga/emisar
**What it is:** emisar, by Andrew Dryga. Elixir (portal) plus Go (runner, bridge), license "Other" (NOASSERTION, so check it before use). Server and policy gateway. [Repo](https://github.com/AndrewDryga/emisar).

**Why it's here:** New to this series. [v0.60.0](https://github.com/AndrewDryga/emisar/releases) (2026-11-18) patches a Plug multipart CVE and builds with Go 1.27.4 to pick up another CVE fix. v0.59.0 (Nov 10) added a CLI-vs-MCP guide and Google Cloud packs. v0.58.0 (Nov 8) added packs for Dataproc, NATS and Betterstack. Roughly one release every two to three days.

**What it solves:** Letting an agent investigate and operate infrastructure without handing it a shell. For ops and security-minded teams.

**General design:**
- Three parts: an Elixir/Phoenix portal (console, MCP API, policy, audit), a Go runner on each host, and a Go stdio-to-HTTP bridge (`emisar-mcp`).
- Actions come in versioned, content-addressed "packs". A pack declares the executable, argv shape, argument schema, risk level, timeout, output limits and redaction. The model picks an action with typed arguments and never writes a command line.
- Policy is evaluated before dispatch (scope, risk, standing grants, approvals). Runners keep a hash-chained JSONL journal. Optional signed (Ed25519 / P-256) bridge attestation stops the control plane widening a call.
- The runner dials out over a TLS WebSocket and has no inbound listener. Remote clients use OAuth over HTTP. The runner does not sandbox what it runs.
- A `shell` pack exists as default-denied break-glass.

**Traction:** 485 stars, 28 forks, 0 open issues. Created 2026-05-19. Latest v0.60.0. Discussion links: none found.

**Takeaway for a macOS MCP server builder:** The "declared typed action with a risk level" model is a good fit for AppleScript/Shortcuts-style tools, where an agent should not run arbitrary scripts. Borderline for size: it is small but clearly not star-farmed.

## 6. db-lyon/ue-mcp
**What it is:** ue-mcp, by db-lyon. C++ with a Node CLI, MIT. Server. [Repo](https://github.com/db-lyon/ue-mcp).

**Why it's here:** [v1.4.14](https://github.com/db-lyon/ue-mcp/releases) (2026-11-17).
- Supports Unreal Engine 5.4 to 5.9, installed with `npx ue-mcp@latest`.
- Fab library sync, search and download.
- Play-in-Editor input recording now captures cursor and UMG pointer events and replays them.
- World Partition tools and DataTable import from CSV.
- Tools can read native Windows editor dialogs and set their values.
- The daemon accepts headers up to 64 KiB.

**What it solves:** Driving Unreal Engine from an agent, including editor UI.

**General design:** An editor-side bridge plus a daemon. It picks a free port when Windows reserves a range. I did not read how the tools are grouped.

**Traction:** 513 stars, 77 forks. Created 2026-02-24.

**Takeaway for a macOS MCP server builder:** The "read and click native dialogs" and record/replay of input are close cousins of macOS Accessibility automation.

## 8. labstack/pitot
**What it is:** Pitot, by LabStack. Go, Apache-2.0. Server (observability), borderline. [Repo](https://github.com/labstack/pitot).

**Why it's here:** Posted as a Show HN on 2026-11-18 (3 points, 0 comments). It is alpha and not a "major update", but it is a clean example of a new streamable-HTTP MCP server on spec `2026-07-28`.

**What it solves:** Local OpenTelemetry storage and querying that agents can also use.

**General design:** A single binary. It ingests OTLP, stores Parquet queried by DuckDB, and keeps product state in SQLite. MCP is at `/mcp` over streamable HTTP, serves `2026-07-28` plus older versions, and uses the same typed query tools as its built-in agent. Auth is a local login link or OIDC, a bearer token for ingest, and OAuth for MCP clients with browser scope approval.

**Traction:** 139 stars, 3 forks. Created 2025-12-15. Latest release: unknown. HN: [Show HN](https://github.com/labstack/pitot).

**Takeaway for a macOS MCP server builder:** A reference for OAuth with browser-approved scopes on a local server.

**What it is:** The official TypeScript SDK. TypeScript. Tooling (SDK). [Repo](https://github.com/modelcontextprotocol/typescript-sdk). Stars, forks, license: not fetched.
