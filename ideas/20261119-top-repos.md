# Top GitHub repos: 2026-11-19

## TL;DR
- **Agent skills are still the biggest category.** Nine of the 15 picks are skills, skill libraries or plugins for coding agents (superpowers, Claude-BugHunter, last30days-skill, CLI-Anything, cursor/plugins, stitch-skills, diagram-design, rust-anything, inference-optimisation-skill).
- **"Skills" are specialising.** Beyond general workflows, today's skills cover bug bounty hunting, diagram drawing, local LLM speed tuning and incremental Rust ports.
- **Small, reproducible models and robots.** `tiny-voca` (4.5M-parameter text-to-speech, about $9.56 of GPU time) and `minimind` (a 64M LLM trained from scratch) are about doing AI cheaply. MIT's `pear` trains reasoning models in simulation to drive real robot arms.
- **Established infrastructure holds its place.** Firecrawl (web data for agents), OpenVINO (inference) and AFFiNE (notes/whiteboard) all gained stars alongside the new projects.
- **Caution.** The newest-repos list is full of probable star-farming (game "ports", video-clipper clones, repos with no language and thousands of stars). I skipped those. `Claude-BugHunter` is a borderline pick (see its entry).

**Method notes.** "Stars today" for picks 1-5 and 7-12 comes from the GitHub Trending daily page. That page was read through a summarising fetch tool rather than verbatim, so treat those numbers as approximate. Totals, forks, issues, license, creation date, pushed date and latest release come from `api.github.com/repos/OWNER/REPO` and `/releases/latest`. Picks 6 and 13-15 were not on Trending, so "stars today" is unknown. They came from the API search for repos created in the last week, sorted by stars. Design notes come from each repo's rendered README page. I did not read source code. HN: I checked the front page and Show HN (points>20). None of these repos appeared, so HN traction is "none found". Reddit was not checked. Contributor counts were not retrieved ("unknown"). Repeat markers compare with the 2026-11-18 report (and 11-17 for paper-orchestra-era picks, which I did not re-check).

## 1. obra/superpowers
- **What it is:** [obra/superpowers](https://github.com/obra/superpowers). Shell. MIT. *Also featured 2026-11-18 (321,450 stars then); about +800 since.*
- **Domain:** AI agents.
- **What it solves:** Coding agents tend to jump straight to code. Superpowers gives them a repeatable process, for developers who use agents on real projects.
- **General design:** A set of composable "skills" (Markdown instructions) plus bootstrap instructions. The workflow runs brainstorming, then git worktrees, then writing plans, then subagent-driven development or executing plans, with test-driven development, code review and branch finishing along the way. Installs as a plugin for many harnesses (Claude Code, Codex, Cursor, Gemini CLI and others). The skills are plain text, so there are no runtime dependencies listed. Unlike single-purpose skills, it is an end-to-end methodology.
- **Traction:** +2,028 stars today (largest on Trending), 322,258 total, 28,643 forks, 352 open issues. Created 2025-10-09. Latest release v7.0.2 (2026-11-03). Contributors: unknown. HN: none found today.

## 2. elementalsouls/Claude-BugHunter
- **What it is:** [elementalsouls/Claude-BugHunter](https://github.com/elementalsouls/Claude-BugHunter). Python. MIT.
- **Domain:** Security / AI agents.
- **What it solves:** Gives Claude Code a bundle of bug-bounty and external red-team know-how, for security researchers working on targets they are authorized to test. The README restricts use to authorized targets.
- **General design:** A skill bundle: 82-83 skills (the About text and README disagree), 15 slash commands, and 681 patterns from disclosed reports. Skills auto-load by topic. An `engine/` maps the attack surface and routes findings, and a Python `cbh` CLI is included. Optional integrations: Burp MCP and ProjectDiscovery tools. Install as a plugin or copy into `~/.claude`.
- **Traction:** +1,349 stars today, 12,879 total, 1,615 forks, 11 open issues. Created 2026-05-05. Latest release v2.1 (2026-06-05), last push 2026-11-19. Discussion: none found. *Borderline pick:* 11 open issues against 12.9k stars is a low ratio and growth is fast for a niche tool, so stars may be partly inflated. I did not audit it.

## 3. mvanhorn/last30days-skill
- **What it is:** [mvanhorn/last30days-skill](https://github.com/mvanhorn/last30days-skill). Python. MIT. *Also featured 2026-11-18 (70,217 stars then); about +750 since.*
- **Domain:** AI agent skills / research.
- **What it solves:** Answers "what has happened on topic X in the last 30 days?" by pulling from many social and web sources, for people who want a cited brief rather than a list of links.
- **General design:** Searches Reddit, X, YouTube, Hacker News, Polymarket and the web in parallel, ranks by engagement, merges duplicate coverage and writes a cited summary. Optional SQLite store, watchlists and JSON output. Needs Python 3.12+, Node.js (vendored X client) and yt-dlp. Reddit, HN, Polymarket and GitHub need no keys; other sources use optional API keys.
- **Traction:** +954 stars today, 70,963 total, 6,318 forks, 23 open issues. Created 2026-01-23. Latest release v4.4.0 (2026-11-20 per API, one day after today's date as returned). Discussion: none found.

## 4. HKUDS/CLI-Anything
- **What it is:** [HKUDS/CLI-Anything](https://github.com/HKUDS/CLI-Anything). Python. Apache-2.0. *Also featured 2026-11-18 (59,960 then); about +780 since.*
- **Domain:** AI agents / dev tools.
- **What it solves:** Agents work best through command lines, but much software only has a GUI. This generates a CLI for it.
- **General design:** A 7-phase generator (`/cli-anything <path-or-repo>`) builds a Python Click CLI from the target's source. Each generated CLI has a REPL and a `--json` flag, and calls the real backend (LibreOffice headless, Blender and so on). A package manager, CLI-Hub (`pip install cli-anything-hub`), shares them. Requires Python 3.10+.

## 5. firecrawl/firecrawl
- **What it is:** [firecrawl/firecrawl](https://github.com/firecrawl/firecrawl). TypeScript. AGPL-3.0 (SDKs and some UI MIT).
- **Domain:** Web data / AI agents.
- **What it solves:** Agents need clean web content and search results. Firecrawl turns pages into LLM-ready data through one API.
- **General design:** Endpoints for search, scrape, crawl, map, interact and agent. The repo holds a self-hosted server (`apps/api`, Docker Compose with Redis, PostgreSQL and a browser service) and "Firecrawl Local", a Rust binary (`cargo install firecrawl-local`) serving the v2 API on localhost:3002. SDKs exist for Python, Node, Go, Java, Rust, Ruby, .NET, PHP and Elixir. It now also advertises 550+ data providers. AGPL is stricter than most alternatives for hosted use.
- **Traction:** +825 stars today, 204,480 total, 10,717 forks, 850 open issues. Created 2024-04-15. Latest release v2.11.0 (2026-06-19); last push 2026-11-20. Discussion: none found.

## 6. erkamyaman/rust-anything
- **What it is:** [erkamyaman/rust-anything](https://github.com/erkamyaman/rust-anything). Rust. MIT. *Also featured 2026-11-18 (3,684 stars then); +1,835 since, now v2.1.0.*
- **Domain:** Dev tools / Rust.
- **What it solves:** Rewriting an app in Rust all at once is risky. This lets you port one unit at a time and prove each matches the original.
- **General design:** A CLI, MCP server and agent skill. It records the original's behavior on generated inputs, creates a Rust crate plus a wrapper (`bridge`) that keeps the original API, replays the recorded cases against the port (`diff`), then benchmarks and gates it. When every unit passes, `app lift` produces a pure Rust app. The README says the agent or a person writes the Rust; the tool does not translate code. Sources: TS/JS, Python, C, Go, Ruby, Java, Kotlin (PHP and C# planned). Install with `cargo install rust-anything`.
- **Traction:** Stars today unknown (not on Trending); 5,519 total, 445 forks, 1 open issue. Created 2026-11-16 (about 3 days old). Latest release v2.1.0 (2026-11-19). Discussion: none found. Very fast growth with one open issue is a mild star-inflation flag.

## 10. openvinotoolkit/openvino

- **Domain:** ML inference.
- **What it solves:** Running trained models fast on Intel CPUs, GPUs and NPUs, for people deploying AI on laptops, edge devices and servers.

## 11. jingyaogong/minimind
- **What it is:** [jingyaogong/minimind](https://github.com/jingyaogong/minimind). Python. Apache-2.0.
- **Domain:** LLM training / education.
- **What it solves:** Shows the whole LLM training pipeline at a size one person can afford. README claims about 2 hours of SFT on one RTX 3090 for a ~64M model (author's claim; I did not reproduce it).
- **General design:** Pure-PyTorch implementations of pretraining, SFT, LoRA, DPO, RL (PPO, GRPO, CISPO), tool use, agentic RL and distillation. The model is a decoder-only Transformer with RoPE, RMSNorm and SwiGLU, plus an MoE variant. Includes an OpenAI-compatible server and export to llama.cpp, vLLM and Ollama. README is mainly Chinese (`README_en.md` exists).
- **Traction:** +238 stars today, 67,126 total, 8,810 forks, 83 open issues. Created 2024-07-27. Release "v2" is docs-only (2025-10-21). Discussion: none found.

## 14. mit-han-lab/pear
- **What it is:** [mit-han-lab/pear](https://github.com/mit-han-lab/pear). Python. Apache-2.0.
- **Domain:** Robotics / reinforcement learning.
- **What it solves:** Training language-style reasoning models that can directly control real robots, without costly real-world training.
- **General design:** A post-training engine for agentic robotics built on veRL, using asynchronous GRPO, FSDP and LMCache. Training runs in simulators (MuJoCo/LIBERO, Isaac Sim with RoboDojo and RoboLab-120). Deployment uses a vLLM server (RTX 5090 or GB300) driving YAM or SO-101 arms. Targets NVIDIA Blackwell and Hopper.
- **Traction:** Stars today unknown; 737 total, 48 forks, 5 open issues. Created 2026-11-13. No releases. Discussion: none found. Lower stars but a research lab with a genuinely novel approach.

## 15. sybil-solutions/inference-optimisation-skill
- **What it is:** [sybil-solutions/inference-optimisation-skill](https://github.com/sybil-solutions/inference-optimisation-skill). Python. MIT.
- **Domain:** AI agents / LLM serving.
- **What it solves:** Speeds up local LLM serving (decode, speculative decoding, prefill, KV cache, startup, time to first token) in a disciplined way.
- **General design:** `SKILL.md` prescribes a method: compute the theoretical ceiling, change one variable at a time, measure against interleaved controls, log everything, and gate on long-context retrieval. Scripts (`bench.py`, `ceiling.py`, `queue.sh`, `mem.sh`) use only standard-library Python and bash, plus any OpenAI-compatible server. Benchmark numbers in the README are the author's own on specific hardware.
- **Traction:** Stars today unknown; 1,272 total, 114 forks, 6 open issues. Created 2026-11-16 and last pushed the same day (one commit's worth of history). No releases. Discussion: none found. *Borderline pick:* a day-old repo with no follow-up commits.
